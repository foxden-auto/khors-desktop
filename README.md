# KHORS Desktop

Универсальный открытый VPN/прокси-клиент для Windows. Импортирует ссылки и подписки (VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard) и подключается через ядра Xray-core и sing-box. Режимы: системный прокси и TUN, Kill Switch, маршрутизация, защита от утечек DNS.

Работает с любыми совместимыми серверами.

Статус: в разработке. План — [ROADMAP.md](ROADMAP.md), техническое задание — [docs/SPEC.md](docs/SPEC.md).
