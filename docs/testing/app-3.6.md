# Живая проверка 3.6: гео-базы

Гео-базы — списки доменов (`geosite.dat`) и IP-адресов (`geoip.dat`) по странам и категориям. Они нужны правилам
маршрутизации (пресет «Обход для России» — пункт 3.5); в этой сборке правил ещё нет, проверяется только загрузка.
Окно хранит свою копию в `%APPDATA%\KHORS\geo`, служба KHORS — свою в `%ProgramData%\KHORS\geo` (для режима TUN).
Источники — релизы v2fly на GitHub (запасной — jsDelivr), каждый файл сверяется с контрольной суммой релиза.

**Службу переустановите из этой сборки** («Настройки → Служба KHORS → Удалить», затем «Установить»): версия протокола
изменилась.

102. Запустите KHORS, подождите ~30 секунд, откройте «Настройки → Гео-базы». **Ожидается:** у обоих файлов «обновлено
     <дата и время>», размер около 2,2 МБ и 22 МБ; в `%APPDATA%\KHORS\geo` — `geosite.dat` и `geoip.dat`.
103. Сразу нажмите «Обновить сейчас». **Ожидается:** «Обновление…» несколько секунд, даты файлов не изменились
     (файлы совпадают с релизом — скачиваются только контрольные суммы).
104. Строка «Копия службы (режим TUN)». **Ожидается:** «обновлена <дата>». В `%ProgramData%\KHORS\geo` те же два файла.
     Свойства папки `%ProgramData%\KHORS` → «Безопасность»: «Пользователи» — только чтение и выполнение; SYSTEM и
     «Администраторы» — полный доступ.
105. Удалите службу («Удалить»). **Ожидается:** папки `%ProgramData%\KHORS` нет; строка «Копия службы…» — «служба не
     установлена или не отвечает». Установите службу снова. **Ожидается:** через полминуты-минуту копия службы снова
     «обновлена <дата>» (служба скачивает её сразу после установки).
106. Отключите интернет (Wi-Fi/кабель), удалите `%APPDATA%\KHORS\geo\geoip.dat`, нажмите «Обновить сейчас».
     **Ожидается:** красная строка «Не удалось загрузить: нет связи с GitHub.»; у geoip — «ещё не загружен».
     Включите интернет, «Обновить сейчас» — файл снова есть, красной строки нет.
107. (Необязательно) Подключитесь (любой профиль, «Системный прокси»), повторите шаг 106 без отключения интернета, но заблокировав
     github.com и jsdelivr.net (например, строкой `0.0.0.0 github.com` в `hosts` — нужны права администратора).
     **Ожидается:** файл загружается через подключённый KHORS. Верните `hosts`.
108. Снимите «Проверять обновления раз в сутки», перезапустите KHORS. **Ожидается:** флажок остался снятым. Верните его.
109. «О приложении». **Ожидается:** строка про гео-базы: domain-list-community (MIT), geoip (CC BY-SA 4.0), DB-IP (CC BY 4.0).
