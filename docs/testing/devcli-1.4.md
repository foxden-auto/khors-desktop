# Живая проверка 1.4: Xray по ссылке (khors-devcli)

Утилита разработчика: ссылка → профиль → Xray → тестовый запрос через прокси. Системный прокси Windows **не меняется** (это пункт 1.5).
Ссылка остаётся на вашем компьютере; всё, что утилита выводит, замаскировано — вывод можно пересылать.

Если у вас включён другой VPN в режиме TUN, проверка тоже работает: Xray подключается к серверу через его туннель.

## Шаги

1. Распакуйте `khors-devcli-win-x64.zip` (или откройте папку `artifacts\devcli-win-x64`).
2. Положите ссылку на тестовый сервер в файл `link.txt` рядом с `khors-devcli.exe` (одна строка).
3. Запустите `khors-devcli.exe`.
   **Ожидается:** `Xray запущен`, затем `Проверка через прокси: HTTP 204 за … мс` и `Подключение работает`.
4. Проверка браузером (Firefox): Настройки → Сеть → Ручная настройка: SOCKS5 `127.0.0.1`, порт `10808`, включить «Отправлять DNS-запросы через прокси». Откройте `https://www.cloudflare.com/cdn-cgi/trace`.
   **Ожидается:** `ip=` — адрес вашего сервера. После проверки верните в Firefox «Без прокси».
   Или в другом окне: `curl.exe -x socks5h://127.0.0.1:10808 https://www.cloudflare.com/cdn-cgi/trace`
5. Падение ядра: в Диспетчере задач завершите `xray.exe`.
   **Ожидается:** сразу строка `!! Xray завершился неожиданно` и выход утилиты.
6. Снова запустите утилиту и закройте её окно крестиком (аварийное завершение).
   **Ожидается:** в Диспетчере задач не осталось `xray.exe`.

## Что прислать

- Вывод утилиты из шага 3 (он замаскирован).
- Результаты шагов 4–6: да/нет.
- Если не подключилось — запустите `khors-devcli.exe --loglevel info` и пришлите вывод.
