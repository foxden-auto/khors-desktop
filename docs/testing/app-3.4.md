# Живая проверка 3.4: удалённый DNS

В режиме TUN KHORS перехватывает все DNS-запросы компьютера и отправляет их на удалённый DNS через сервер — провайдер их
не видит. Удалённый DNS выбирается в «Настройки → DNS»: пресет (Cloudflare, Google, Quad9, AdGuard — DoH или DoT) или свой
адрес. Он же используется для WireGuard в любом режиме. В режиме «Системный прокси» имена сайтов разрешает сервер, настройка
не влияет. Изменение действует со следующего подключения.

Проверка утечек — https://browserleaks.com/dns (или https://dnsleaktest.com, «Extended test»): в списке должны быть только
серверы выбранного провайдера, не DNS вашего интернет-провайдера.

**Перед проверкой выключите другой VPN в режиме TUN.** Служба KHORS должна быть переустановлена из этой сборки
(«Настройки → Служба KHORS → Удалить», затем «Установить»): старая служба ответит, что версия протокола не совпадает.

94. «Настройки → DNS». **Ожидается:** выбран «Cloudflare — DoH (1.1.1.1)» (как было до настройки), поле своего адреса скрыто.
95. TUN, профиль VLESS + REALITY, «Подключить», browserleaks.com/dns. **Ожидается:** только Cloudflare.
96. «Отключить», выберите «Google — DoT (8.8.8.8)», подключитесь. **Ожидается:** сайты открываются, browserleaks — только Google.
    Повторите для «Quad9 — DoH» и «AdGuard — DoT» (реклама на сайтах при AdGuard частично пропадает).
97. Выберите «Свой адрес», введите `quic://dns.example.com`. **Ожидается:** красная подсказка «Поддерживаются только…»;
    подключение работает с последним верным DNS (из шага 96).
98. Введите `https://dns.google/dns-query` (адрес по имени). **Ожидается:** подсказка исчезла; после переподключения
    сайты открываются, browserleaks — Google.
99. Введите адрес DNS вашего роутера, например `192.168.1.1` (адрес в локальной сети идёт напрямую, не через сервер).
    **Ожидается:** сайты открываются; browserleaks показывает DNS вашего провайдера — это ожидаемо для такого выбора.
100. Профиль WireGuard (если есть) в режиме «Системный прокси» с пресетом «Quad9 — DoT». **Ожидается:** сайты через прокси
     открываются.
101. Закройте KHORS, откройте снова. **Ожидается:** в «Настройки → DNS» выбор сохранился. Верните «Cloudflare — DoH».

Что прислать: результаты шагов 94–101; при ошибке — текст под статусом и «Лог ядра» (он замаскирован). Ссылки не присылайте.
