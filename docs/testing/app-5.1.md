# Живая проверка 5.1: установщик и переносимый ZIP

Файлы — в `artifacts\installer\` (в CI — артефакт `khors-desktop-release-win-x64`):
- `khors-desktop-<версия>-win-x64-setup.exe` — установщик (Inno Setup): окно, служба и ядра в `%ProgramFiles%\KHORS`,
  служба KHORS — по задаче (отмечена по умолчанию; уже установленная обновляется всегда);
- `khors-desktop-<версия>-win-x64-portable.zip` — без установки; профили и настройки — в папке `data` рядом с
  `khors-desktop.exe` (признак — файл `khors.portable`).

Установщик не подписан: Windows SmartScreen покажет «Система Windows защитила ваш компьютер» → «Подробнее» →
«Выполнить в любом случае» (подпись кода — ROADMAP «Позже»).

Перед проверкой закройте KHORS из прежних сборок. Профили в `%APPDATA%\KHORS` установщик не трогает.

176. Запустите установщик. **Ожидается:** выбор языка (русский), запрос прав администратора; на шаге задач
     «Установить службу KHORS…» отмечено, «Создать значок на Рабочем столе» — нет. После установки — «Запустить
     KHORS». **Ожидается:** KHORS открылся с вашими профилями; в «Пуске» есть KHORS; в `%ProgramFiles%\KHORS` —
     `khors-desktop.exe`, `khors-service.exe`, `cores\`, `LICENSE`, `NOTICE`, `service\`; «Настройки → Служба KHORS» —
     «работает, версия 1.0.0».
177. Подключитесь в режиме «Системный прокси» и в TUN. **Ожидается:** оба режима работают.
178. Не закрывая KHORS, запустите установщик ещё раз (обновление). **Ожидается:** установщик сообщает, что KHORS
     открыт, и предлагает закрыть его (или закрывает сам); после установки служба снова «работает, версия 1.0.0»,
     профили на месте, задача «служба» была отмечена.
179. «Параметры → Приложения → KHORS Desktop → Удалить». **Ожидается:** вопрос «Удалить также профили и настройки…» —
     ответьте «Нет». После удаления: нет `%ProgramFiles%\KHORS`; `sc query KhorsService` — «служба не установлена»;
     фильтров KHORS в WFP и адаптера KHORS нет (команды из `app-4.4.md`); системный прокси — как до KHORS;
     `%APPDATA%\KHORS` на месте (docs/SPEC.md, 7.6).
180. Установите снова, Kill Switch «Постоянно» (TUN), отключитесь, удалите программу. **Ожидается:** после удаления
     интернет работает, фильтров KHORS нет.
181. Удалите программу ещё раз (после повторной установки), на вопрос о данных ответьте «Да». **Ожидается:**
     `%APPDATA%\KHORS` удалён. (Перед этим шагом сохраните копию `%APPDATA%\KHORS`, если профили нужны.)
182. Распакуйте ZIP в новую папку (например, `Рабочий стол\khors-portable`) и запустите `khors-desktop.exe`.
     **Ожидается:** профилей нет, рядом с exe появилась папка `data`; добавьте профиль, подключитесь в режиме
     «Системный прокси» — работает; `%APPDATA%\KHORS` не изменился (дата изменения `profiles.json`). Службу для TUN
     можно установить кнопкой из окна — она ставится из этой папки.
183. (Необязательно.) Тихая установка из командной строки администратора:
     `khors-desktop-1.0.0-win-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES`. **Ожидается:** установлено со службой,
     без окон.

Что прислать: результаты шагов 176–183; при ошибке — текст сообщения установщика и `%TEMP%\Setup Log*.txt`
(если установщик запускали с `/LOG`).
