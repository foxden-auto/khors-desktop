# Живая проверка 2.5: выбор ядра

Ядро выбирается само: Xray, если он может запустить профиль, иначе sing-box. Под именем профиля в списке видно,
какое ядро он использует («… · TCP · Xray»). Выбрать ядро вручную — правой кнопкой по профилю → «Ядро».

24. Посмотрите список. **Ожидается:** у VLESS/REALITY, VMess, Trojan, Shadowsocks — «Xray»; у Hysteria2, TUIC, WireGuard — «sing-box».
25. Правой кнопкой по профилю VLESS + REALITY (без `support-x25519mlkem768`) → «Ядро» → «sing-box», подключитесь.
    **Ожидается:** в строке профиля «sing-box», при подключении «Ядро sing-box», сайты открываются.
    С сервером Xray 26.9.8+ возможна ошибка `reality verification failed` — это известное ограничение sing-box, а не KHORS.
26. Верните «Автоматически (сейчас Xray)». **Ожидается:** снова «Xray».
27. Для профиля с `support-x25519mlkem768=true` (ссылки серверов KHORS) или с XHTTP выберите «sing-box».
    **Ожидается:** сообщение «Ядро sing-box не запустит этот профиль: … Выбор ядра не изменён.», отметка в меню остаётся прежней.
28. Для TUIC выберите «Xray». **Ожидается:** такое же сообщение, выбор не меняется.
29. Подключитесь к профилю и, не отключаясь, смените ему ядро. **Ожидается:** профиль переподключается, в статусе — новое ядро.
30. Если есть подписка: смените ядро профилю из подписки, обновите подписку. **Ожидается:** выбор сохранился.
31. Если есть ссылка с `allowInsecure=1` (без `pcs`) или Trojan/VLESS без TLS: **ожидается** «sing-box» в строке профиля и подключение через него
    (раньше — ошибка Xray 26).

Что прислать: результаты шагов 24–31; при ошибке — текст и «Лог ядра» (он замаскирован). Ссылки не присылайте — в них ключи.
