# Живая проверка 5.2а: AmneziaWG через sing-box-extended

Профили AmneziaWG обрабатывает третье внешнее ядро — sing-box-extended (форк sing-box с полем `amnezia`
в WireGuard endpoint), поставляется вместе с Xray и sing-box. Импорт: ссылка `vpn://` (Base64 с текстом
wg-quick `.conf`), файл или фрагмент `.conf`, `wireguard://` с параметрами AWG, Clash-подписка с
`amnezia-wg-option`, sing-box-подписка с endpoint `amnezia`. Поставка — 1.14.1-extended-2.7.2.

**Службу переустановите из этой сборки** (протокол 10).

192. Импортируйте AWG-подписку (или ссылку `vpn://` / файл `.conf`). **Ожидается:** профиль в списке, протокол
     отображается как `AmneziaWG`; в карточке профиля ядро — «sing-box-extended» (автовыбор).
193. Подключитесь в режиме «Системный прокси». **Ожидается:** статус «Подключено», пинг/тест задержки проходит,
     сайты открываются через прокси (проверьте 2ip.ru — адрес сервера AWG).
194. Отключите прокси-режим, включите TUN, подключитесь. **Ожидается:** сайты открываются; проверка утечки DNS
     (dnsleaktest.com) показывает удалённый DNS; провайдерский DNS не виден.
195. Kill Switch «Пока подключено», TUN. Убейте процесс ядра sing-box-extended в Диспетчере задач. **Ожидается:**
     приложение показывает обрыв и переподключается; без туннеля трафик не идёт (утечек нет), после
     переподключения интернет работает.
196. «Настройки → Ядра». **Ожидается:** у sing-box-extended — «Окно: 1.14.1-extended-2.7.2 (из поставки)» и то же
     у службы; «Проверить обновления» не предлагает сломанную 1.14.3-extended-2.7.3 (в её Windows-архиве лежит
     Linux-файл — версия исключена).

Что прислать: результаты шагов 192–196; при ошибке — замаскированный лог («Собрать отчёт» или копия журнала)
без ссылок, токенов и ключей.
