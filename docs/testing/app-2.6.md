# Живая проверка 2.6: ссылки и QR-коды

Ссылки и QR-коды профилей содержат ключи доступа — не присылайте их, только результаты шагов.

32. Правой кнопкой по профилю → «Копировать ссылку». Вставьте ссылку в другой клиент (например, на телефоне) или удалите профиль
    и вставьте её обратно через «Вставить из буфера». **Ожидается:** профиль такой же, подключается.
33. Правой кнопкой по профилю → «Показать QR-код». **Ожидается:** окно с чёрно-белым кодом и предупреждением о ключах.
    Отсканируйте код камерой телефона клиентом (v2rayNG, Hiddify, KHORS для Android). **Ожидается:** профиль импортируется и подключается.
34. В окне QR — «Копировать картинку», удалите профиль, затем «Вставить из буфера». **Ожидается:** профиль вернулся (код прочитан с картинки).
35. Сохраните картинку с QR-кодом в файл (скриншот, PNG/JPG). Стрелка у «Вставить из буфера» → «Из файла…» → выберите её.
    **Ожидается:** профиль импортирован. Файл без кода — «В файле не найден QR-код».
36. «Из файла…» → текстовый файл со ссылками или YAML/JSON-конфиг (экспорт панели). **Ожидается:** профили импортированы.
37. Для профиля с длинной ссылкой (VLESS с `pqv`) — «Показать QR-код». **Ожидается:** код показан (плотный) или понятное сообщение,
    что ссылка слишком длинная.

38. Откройте картинку с QR-кодом (из шага 35) на экране поверх других окон. Стрелка у «Вставить из буфера» → «QR-код с экрана».
    **Ожидается:** окно KHORS на мгновение пропадает, профиль импортирован. Если код на втором мониторе — тоже находится.
    Без кода на экране — «На экране не найден QR-код…».
