# Живая проверка 4.1: Kill Switch

Kill Switch (режим TUN) блокирует трафик компьютера, если туннель KHORS оборвался, вместо того чтобы пустить его
напрямую. Фильтры ставит служба KHORS через Windows Filtering Platform; их имена начинаются с «KHORS».
Разрешено всегда: сам компьютер (loopback), адаптер KHORS, ядра в каталоге службы, DHCP и — если отмечено —
локальная сеть.

Признак — `https://www.cloudflare.com/cdn-cgi/trace`: через KHORS — адрес сервера; при блокировке страница не
открывается («Нет подключения к Интернету» / ERR_NETWORK_ACCESS_DENIED). Признак локальной сети — страница роутера
(обычно `http://192.168.0.1` или `http://192.168.1.1`).

**Службу переустановите из этой сборки** (протокол 7). Если что-то пошло не так и интернет пропал: «Настройки →
Kill Switch → Выключен»; если окно недоступно — удалите службу («Настройки → Служба KHORS → Удалить» или от имени
администратора `khors-service.exe uninstall` из папки сборки): при удалении все фильтры KHORS снимаются.

129. (Необязательно, для разработки) Командная строка **от имени администратора** в папке репозитория:
     `set KHORS_WFP_TESTS=1` и `dotnet test tests\Khors.Platform.Windows.Tests -- --filter-class *WfpKillSwitchIntegrationTests`.
     **Ожидается:** 1 тест пройден (на ~1 секунду блокирует сеть и снимает фильтры).
130. «Настройки → Kill Switch»: по умолчанию «Выключен», «Разрешить локальную сеть» отмечено. В режиме «Системный
     прокси» вариант «Постоянно» недоступен. Переключите режим на TUN, выберите «Пока подключено».
131. Подключитесь (TUN). **Ожидается:** cloudflare — адрес сервера; роутер открывается.
132. Диспетчер задач → «Подробности» → снимите задачу `sing-box.exe` (процесс SYSTEM — Диспетчер попросит права
     администратора). **Ожидается:** «Ошибка подключения», жёлтая строка «Kill Switch блокирует трафик: подключение
     оборвалось…» и ссылка «Снять блокировку»; cloudflare не открывается; роутер открывается. Нажмите «Снять
     блокировку». **Ожидается:** строка исчезла, cloudflare открывается напрямую (ваш адрес).
133. Подключитесь, снимите задачу `khors-desktop.exe`. **Ожидается:** интернет не работает (роутер — работает).
     Запустите KHORS. **Ожидается:** жёлтая строка о блокировке. Нажмите «Подключить» — интернет через сервер;
     «Отключить» — интернет напрямую, строки нет.
134. Снимите «Разрешить локальную сеть», подключитесь. **Ожидается:** роутер не открывается, интернет — через сервер.
     Верните флажок — роутер открывается без переподключения.
135. Выберите «Постоянно» (режим TUN). **Ожидается:** «Системный прокси» стал недоступен. Отключитесь. **Ожидается:**
     жёлтая строка «…KHORS не подключён (режим «Постоянно»)», интернета нет, ссылки «Снять блокировку» нет.
     Перезагрузите компьютер и до запуска KHORS проверьте: интернета нет, роутер открывается. Запустите KHORS,
     подключитесь — интернет через сервер.
136. Выберите «Выключен». **Ожидается:** при отключении интернет работает напрямую.
137. Снова «Постоянно», затем удалите службу. **Ожидается:** интернет работает напрямую. От имени администратора:
     `netsh wfp show filters file=%TEMP%\wfp.xml` и `findstr /c:"KHORS" %TEMP%\wfp.xml` — ничего не найдено.
     Установите службу снова.

Что прислать: результаты шагов 130–137 (и 129, если запускали); при ошибке — текст красной строки в разделе
Kill Switch и, если есть, записи службы в «Просмотре событий» (Журналы Windows → Приложение, события KHORS за время проверки).
