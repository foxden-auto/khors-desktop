# Живая проверка 4.2: IPv6 в режиме TUN

В режиме TUN весь IPv6 компьютера и так идёт в адаптер KHORS, мимо туннеля он не уходит. Но у многих серверов нет
выхода в IPv6. Раньше IPv6-адрес, полученный мимо DNS KHORS (Secure DNS браузера, кэш, адрес в программе),
приводил к «висящему» сайту. Теперь по умолчанию («Настройки → Маршрутизация → IPv6 через VPN» снят) IPv6 в TUN
отклоняется сразу, и программа переходит на IPv4. С Kill Switch IPv6 через адаптер KHORS ещё и блокируется
фильтром WFP. Флажок включают только для сервера с выходом в IPv6.

**Службу переустановите из этой сборки.** Конфиг TUN строит служба, а старая служба флажок не учитывает.

Команды — в обычной командной строке (`curl.exe` есть в Windows 10/11).

138. «Настройки → Маршрутизация»: флажок «IPv6 через VPN (режим TUN)» снят. Подключитесь в TUN, Kill Switch
     выключен. Откройте `https://test-ipv6.com`. **Ожидается:** IPv4-адрес — адрес сервера, IPv6-адреса нет,
     страница не жалуется на «утечку» и не висит.
139. `curl.exe -6 -m 10 https://ipv6.google.com`. **Ожидается:** `Could not resolve host` — DNS KHORS не отдаёт
     IPv6-адреса. Затем IPv6-адрес без DNS:
     `curl.exe -6 -m 10 -s -o NUL -w "%{http_code} %{time_total}\n" "https://[2606:4700:4700::1111]/cdn-cgi/trace"`.
     **Ожидается:** код `000` и время меньше 1 с (соединение отклонено сразу), а не ожидание 10 с.
140. `curl.exe -m 10 https://www.cloudflare.com/cdn-cgi/trace`. **Ожидается:** `ip=` — адрес сервера (IPv4).
     В браузере с включённым Secure DNS (Chrome/Edge: «Настройки → Конфиденциальность → Безопасный DNS») сайты
     с IPv6 (google.com, youtube.com, facebook.com) открываются без задержки.
141. Пресет «Обход для России»: `ya.ru` и `vk.com` открываются, `https://yandex.ru/internet` показывает ваш адрес
     (IPv4 провайдера).
142. Kill Switch «Пока подключено», подключитесь. Повторите вторую команду шага 139. **Ожидается:** ошибка сразу (WFP запрещает
     IPv6 через адаптер KHORS). Шаги 138 и 140 — как раньше. Kill Switch верните в «Выключен».
143. Отметьте «IPv6 через VPN», нажмите «Переподключиться». Если у сервера **нет** IPv6: вторая команда шага 139 — ошибка
     или ожидание до 10 с (так и должно быть: IPv6 ушёл на сервер), обычные сайты открываются (сначала IPv4).
     Если у сервера **есть** IPv6: `curl.exe -6 https://www.cloudflare.com/cdn-cgi/trace` — `ip=` — IPv6-адрес
     сервера, test-ipv6.com показывает IPv6-адрес сервера. Ваш собственный IPv6 нигде не виден.
144. Снимите флажок, переподключитесь. **Ожидается:** снова как в шаге 138.

Что прислать: результаты шагов 138–144; есть ли у сервера IPv6 (если знаете); при ошибке — вывод curl и кусок
журнала («Журнал», «Копировать весь лог»).
