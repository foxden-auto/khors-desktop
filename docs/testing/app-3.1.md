# Живая проверка 3.1: служба KHORS

Служба нужна для режима TUN (этап 3) и защиты сети (этап 4). Пока она только устанавливается, запускается и отвечает окну
по защищённому каналу — режим TUN появится в 3.2. Установка и удаление требуют прав администратора: Windows покажет запрос
UAC, само окно KHORS остаётся без прав администратора. Другой VPN на время этой проверки можно не выключать — служба сеть не трогает.

56. Запустите `khors-desktop.exe`. **Ожидается:** внизу окна «Служба KHORS (режим TUN): не установлена» и «Установить».
57. Нажмите «Установить», согласитесь в окне UAC. **Ожидается:** «Служба KHORS установлена и запущена.»,
    внизу «работает, версия …», вместо «Установить» — «Удалить».
58. Откройте «Службы» (`services.msc`). **Ожидается:** служба «KHORS Service» (имя `KhorsService`), тип запуска
    «Автоматически», выполняется; в свойствах путь `"C:\Program Files\KHORS\service\khors-service.exe"`;
    на вкладке «Восстановление» — перезапуск службы при сбоях.
59. Откройте `C:\Program Files\KHORS\service`. **Ожидается:** `khors-service.exe` и `cores\xray`, `cores\sing-box`.
    Попробуйте создать там файл без прав администратора. **Ожидается:** Windows требует права администратора.
60. Перезапустите KHORS (трей → «Выход», снова `khors-desktop.exe`). **Ожидается:** «работает, версия …».
61. В «Службах» остановите KHORS Service, перезапустите окно KHORS. **Ожидается:** «остановлена», кнопка «Удалить».
    Запустите службу обратно.
62. Перезагрузите компьютер. **Ожидается:** служба запустилась сама, в окне «работает, версия …».
63. Нажмите «Удалить» и откажитесь в окне UAC.
    **Ожидается:** «Отменено: права администратора не выданы.», служба на месте.
64. «Удалить» и согласитесь. **Ожидается:** «Служба KHORS удалена.», внизу «не установлена»; в «Службах» её нет,
    каталога `C:\Program Files\KHORS` нет.

Если установка не удалась: откройте командную строку от имени администратора, перейдите в папку сборки и выполните
`khors-service.exe install` — в ответ будет текст ошибки. Что прислать: результаты шагов 56–64 и текст ошибок, если были.
