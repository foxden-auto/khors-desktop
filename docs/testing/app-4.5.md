# Живая проверка 4.5: матрица Kill Switch (docs/SPEC.md, 7.4)

Kill Switch действует в режиме TUN. Главное требование: ни в одном сценарии трафик не уходит напрямую, пока
блокировка должна стоять. Допустимо только два состояния — «через сервер» или «нет связи».

**Службу переустановите из этой сборки.** Изменилась смена сервера в TUN: новое подключение теперь поднимается раньше,
чем закрывается старое, поэтому блокировка «пока подключено» не снимается ни на миг.

## Как смотреть на утечку

Во время каждого сценария держите открытым окно PowerShell с циклом. Он раз в секунду печатает адрес, с которым вас
видит интернет:

```
while ($true) { $t = Get-Date -Format HH:mm:ss; try { $ip = ((Invoke-WebRequest https://www.cloudflare.com/cdn-cgi/trace -TimeoutSec 3 -UseBasicParsing).Content -split "`n" | Select-String '^ip=') } catch { $ip = 'нет связи' }; "$t $ip"; Start-Sleep 1 }
```

Перед прогоном запишите свой адрес (без KHORS) и адрес сервера. **Утечка — любая строка с вашим адресом там, где по
таблице ожидается «сервер» или «нет связи».** Строки «нет связи» во время переподключения — норма.

## Матрица

| № | Сценарий | «Пока подключено» | «Постоянно» |
|---|---|---|---|
| 164 | Подключение | до подъёма TUN — нет связи, потом сервер | так же |
| 165 | Отключение | сразу ваш адрес (блокировка снята) | нет связи, жёлтая строка «…KHORS не подключён» |
| 166 | Падение ядра (снять задачу `sing-box.exe`) | нет связи во время попыток → сервер (4.3) | так же |

## Шаги

Для каждой клетки: выберите режим в «Настройки → Kill Switch», режим подключения TUN, запустите цикл, выполните
сценарий и сравните строки цикла с таблицей. «Разрешить локальную сеть» — как у вас обычно.

164–175. По строкам таблицы, сначала все в «Пока подключено», затем в «Постоянно» (строки 167, 168, 171 и 174 в
«Постоянно» короче — ожидаемое поведение в таблице). После строки 171 в «Постоянно» проверьте, что до запуска KHORS
открывается роутер, если «Разрешить локальную сеть» отмечено.

Ядра снимаются в Диспетчере задач → «Подробности» (процессы SYSTEM — Диспетчер попросит права администратора).
Для 167 снимите «Настройки → Режим подключения → Переподключаться автоматически», после — верните.

В конце: Kill Switch — как было у вас; если интернет пропал — «Настройки → Сброс сетевых настроек» (4.4).

Что прислать: для каждой строки и режима — «как в таблице» или отличие; для отличия — кусок вывода цикла (адреса
можно заменить на «мой» / «сервер») и что было на экране KHORS.
