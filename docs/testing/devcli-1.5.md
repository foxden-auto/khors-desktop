# Живая проверка 1.5: системный прокси Windows (khors-devcli --system-proxy)

Утилита включает системный прокси Windows на HTTP-вход Xray и возвращает прежние настройки при выходе,
при падении Xray, при закрытии окна и — если окно было «убито» — при следующем запуске.
Прежние настройки сохраняются в `%APPDATA%\KHORS\state\system-proxy.json` до изменения.

Удобный признак пути: внешний адрес в Edge без KHORS — ваш обычный, с прокси KHORS — адрес тестового сервера.
Адрес проверяйте на `https://www.cloudflare.com/cdn-cgi/trace` (строки `ip=` и `loc=`).

## Шаги

1. Откройте в Edge страницу trace. **Ожидается:** обычный внешний адрес.
2. Запустите `khors-devcli.exe --system-proxy` (ссылка — в `link.txt`).
   **Ожидается:** `Системный прокси Windows → 127.0.0.1:10809`; в «Параметры → Сеть и Интернет → Прокси-сервер» — ручной прокси `127.0.0.1:10809`.
3. Обновите trace в Edge. **Ожидается:** адрес тестового сервера.
4. Нажмите Ctrl+C. **Ожидается:** `Системный прокси Windows восстановлен (выход)`; в параметрах — как было до шага 2; trace снова обычный внешний адрес.
5. Снова `khors-devcli.exe --system-proxy`, затем в Диспетчере задач завершите `xray.exe`.
   **Ожидается:** `Xray завершился неожиданно` и сразу `восстановлен (падение Xray)`; trace — обычный внешний адрес.
6. Снова `khors-devcli.exe --system-proxy` и закройте окно крестиком.
   **Ожидается:** прокси в параметрах вернулся как было, trace — обычный внешний адрес.
7. Жёсткое завершение: снова `khors-devcli.exe --system-proxy`, в Диспетчере задач на вкладке «Подробности» завершите `khors-devcli.exe` («Снять задачу»).
   **Сейчас ожидается:** прокси остаётся `127.0.0.1:10809`, Edge не открывает сайты (так и должно быть до следующего запуска).
   Запустите `khors-devcli.exe --system-proxy` ещё раз. **Ожидается:** `После прошлого сбоя: Restored`; после Ctrl+C всё как было.

## Что прислать

- Результаты шагов 1–7: да/нет (и `loc=` из шагов 1, 3, 4).
- Вывод утилиты, если что-то пошло не так (он замаскирован).
