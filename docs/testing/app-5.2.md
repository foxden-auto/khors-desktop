# Живая проверка 5.2: обновление ядер из GitHub Releases

«Настройки → Ядра»: версии Xray и sing-box у окна и у службы, «Проверить обновления», «Обновить ядра», «Откатить на …».
Сеть — только по кнопке. Обновление — в пределах серии этой версии KHORS (Xray 26.x, sing-box 1.14.x): архив
сверяется с SHA-256 из GitHub, новое ядро проверяется конфигами KHORS (`xray run -test`, `sing-box check`) и только
потом включается. Окно хранит ядра в `%APPDATA%\KHORS\cores`, служба — в `%ProgramData%\KHORS\cores` и качает свою
копию сама. Новое ядро действует со следующего подключения.

На 2026-10-08: в серии Xray есть 26.9.30 (в поставке 26.9.9), для sing-box новее 1.14.2 нет.

**Службу переустановите из этой сборки** (протокол 9).

184. «Настройки → Ядра». **Ожидается:** «Окно: 26.9.9 (из поставки)», «Служба: 26.9.9 (из поставки)» для Xray и
     1.14.2 для sing-box; кнопки «Откатить» нет.
185. «Проверить обновления». **Ожидается:** у Xray — «Доступна версия 26.9.30.» (или новее), у sing-box — ничего
     (или «Вышла версия … новой серии…», если 1.15.0 уже вышла), кнопка «Обновить ядра».
186. «Обновить ядра». **Ожидается:** «Загрузка и проверка ядер…», затем «Xray обновлён до 26.9.30.»; строки — «Окно:
     26.9.30», «Служба: 26.9.30», кнопка «Откатить на 26.9.9». Файлы: `%APPDATA%\KHORS\cores\xray\26.9.30\xray.exe`
     и `LICENSE`.
187. Подключитесь в режиме «Системный прокси», затем в TUN. **Ожидается:** работает; в «Журнале» — строка запуска
     Xray с версией 26.9.30 (в TUN для профилей Xray — цепочка). В Диспетчере задач у `xray.exe` («Подробности» →
     столбец «Путь к образу» / «Расположение файла») — путь из `%APPDATA%\KHORS\cores` (окно) или
     `%ProgramData%\KHORS\cores` (служба).
188. Kill Switch «Пока подключено», TUN, подключитесь. **Ожидается:** интернет через сервер (фильтры разрешают новый
     путь ядра). Kill Switch верните как было.
189. «Откатить на 26.9.9». **Ожидается:** «Xray: возвращена предыдущая версия.», строки снова «(из поставки)»;
     после переподключения работает ядро из поставки.
190. Без интернета (Wi-Fi выключен) — «Проверить обновления». **Ожидается:** «Xray: не удалось проверить (нет связи
     с GitHub).», ничего не меняется.
191. (Необязательно.) Остановите службу и обновите ядра. **Ожидается:** окно обновлено, у службы — «служба — не
     обновлена: служба не отвечает»; после запуска службы — снова «Обновить ядра» обновляет только её.

Что прислать: результаты шагов 184–191; при ошибке — текст под кнопками.
